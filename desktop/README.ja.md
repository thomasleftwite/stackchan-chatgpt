# スタックちゃん ホスト Windows版

版: 0.3.0-preview.1 / 2026-10-19。Windows 10/11 x64（Intel/AMD）用。
目的: AtomS3R + Atomic Voice Base A149（Stage2 R01ファームウェア導入済み）の質問を、Windows PCでGeminiへ中継する。

## 使い方

1. StackchanHost.exeを開きます。初回は一時展開のため少し時間がかかります。
2. 端末をデータ通信可能なUSBケーブルで接続し、PCと端末を同じ家庭内LANへ接続します。端末に保存済みのWi-Fi接続設定を使います。
3. 「再検出」を押し、端末のUSBポートと、このPCのLANアドレスを選びます。COM4以外の番号でも使えます。複数LAN/VPNがある場合は端末と同じLANを選びます。
4. このPCで使うGemini APIキーとモデルを入力します。既定モデルは本プロジェクトの既存設定であり、各キーでの利用可否は別途確認してください。
5. 「接続して開始」を押し、端末にPC onlineが出ることを確認。端末を短押ししてから呼びかけ、合図とSpeak now表示後に質問します。
6. 「停止」で中継を終了します。現行の検証用サービスは約10分でも停止します。続けるときは再度開始してください。ウィンドウを閉じる場合も停止処理が終わるまで待ちます。

Python・Node.js・npm・PlatformIO・VS Codeを別途インストールする必要はありません。端末へのファームウェア書込み機能は含みません。初回のキー入力、同一LAN、インターネット接続、端末側の既存Wi-Fi設定は必要です。PCサービス停止時の常時LAN監視は追加していません。Online表示が直近の状態のままでも、次の質問の接続失敗時に利用不可表示へ変わる場合があります。

## キーの扱い

EXEにAPIキーは入っていません。配布先のPCで入力してください。保存チェックがない場合は起動中だけ使用します。設定保存を選んだ場合はWindows DPAPIにより、そのWindowsユーザーで暗号化してLOCALAPPDATA/StackchanHost/settings.jsonへ保存します。この暗号化設定を他PCへコピーして使う方式ではありません。画面やエラー記録にキー・回答本文・録音音声は出しません。音声は会話開始後にGoogle Geminiへ送信され、利用枠を消費します。

## USBドライバ

確認した端末はEspressif USB Serial/JTAG（VID 303A / PID 1001）です。Espressif公式資料ではWindows 10以降はインターネット接続時の自動ドライバ導入を案内しています。対象外のCH340/CH9102/CP210xドライバやWindowsシステムドライバはこのEXEへ混在させていません。初めて接続するPCではWindows Update等の初回認識が必要な場合があります。

COMポートが表示されない場合は、USBケーブル/ポートとデバイスマネージャーを確認し、「USB認識の案内」から公式資料を開いてください。社内PC等でドライバや通信が制限されている場合は管理者の手順に従ってください。アプリはドライバやファイアウォール設定を自動変更しません。
公式: https://docs.espressif.com/projects/esp-iot-solution/en/release-v2.0/usb/usb_overview/usb_serial_jtag.html

## 接続できない場合

- 「端末から応答がありません」: 端末の画面を確認し、必要ならリセットボタンを短押し。ほかのシリアル監視ソフトを閉じて再検出します。
- Wi-Fi/LAN: PCと端末のネットワークを確認。Windowsのファイアウォールで同梱Node.jsの通信許可を求められた場合は、使用する家庭内のプライベートネットワークについて確認します。アプリは公開ネットワーク用の規則を自動追加しません。
- APIエラー: キー、モデル利用可否、Googleの利用枠を確認します。OpenAIキーは不要です。
- USB接触不良はアプリで修復できません。安定した接続で使ってください。

## 同梱物と検証範囲

Python 3.14.4、Tk 8.6、pyserial 3.5、Node.js 24.15.0、@google/genai 2.30.0と固定された実行依存を同梱。ライセンスはアプリの「使い方・ライセンス」で確認できます。

このEXEは開発用プレビューです。コード署名証明書は付与していません。別PCでの起動・ドライバ認識・Windowsの警告・実機Gemini会話は、そのPCでの確認が必要です。検証結果は配布フォルダのVALIDATION.mdを参照してください。OSの保護機能を無効化して使う手順は提供しません。
