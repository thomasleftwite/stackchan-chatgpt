# スタックちゃん ホスト Windows版

0.4.0-preview.1。通常動作はUSB不要。USBは電源または開発診断として利用できます。

## 初回

1. PCをインターネットにつなぎ、Windowsの「設定 → ネットワークとインターネット → モバイルホットスポット」を有効にします。帯域は2.4GHz、十分長い専用パスワードを使用します。
2. 端末の画面ボタンを押しながらリセットするとWiFiManagerが起動します。Stackchan-Setup / 12345678へスマートフォンから接続し、192.168.4.1でPCのホットスポットを設定します。設定APの時間制限はありません。
3. 端末に表示される登録コード（4行×8桁）を確認します。コードはこの端末専用の認証情報です。
4. StackchanHost.exeの接続方式を「Wi-Fi（USB不要）」にし、再検出してPCのホットスポット側のアドレスを選びます。上流の共有Wi-Fiのアドレスは選びません。Windows標準では192.168.137.1がよく使われますが、実際の表示を確認してください。
5. 端末の登録コード32桁とGemini APIキーを入力して開始。端末コードはWindowsユーザー専用に暗号化保存されます。APIキーの保存はチェックボックスで選択できます。
6. 「端末を認証して接続しました」と出たら、端末を短押しして呼びかけます。開始音の終了から約0.7秒後に質問します。

## 次回以降

ホットスポットとホストを起動すれば、端末が保存済みのWi-Fiと認証情報で自動接続します。端末のIP固定や、毎回のUSB設定転送は不要です。ホストは停止するまで動作します。端末はPCゲートウェイのTCP 48443へTLS接続します。
Windows受信許可はホットスポット側だけに限定してください。EXEはホットスポットやファイアウォールを自動変更しません。

## 登録解除・変更

PC側の「端末登録を解除」で保存情報を削除できます。端末はSleeping中の10秒長押し→離す操作で専用キーを更新し、新しいコードを表示します。5秒で離す従来の呼びかけ登録操作は維持しています。
再ペアリングは旧キーが使えなくなるため、PCでも新しいコードを入力します。Wi-Fi設定と呼びかけ登録は消しません。

## USB診断

「USB診断（従来）」を選ぶと従来のUSB設定・一時中継を使えます。これは開発用の平文WS経路で、通常の暗号化通信とは別です。同時に別ツールでUSBポートを開くことはできません。約10分で終了します。

## 保護と制限

通常通信はDHE-PSK-AES128-GCM-SHA256 / TLS1.2。無作為128bitの端末固有キーで相互認証し、HTTPにも認証を要求します。コードは画面とPC入力以外に表示せず、ログや配布物には保存しません。
PC保存はDPAPI暗号化。端末のNVSは現段階ではフラッシュ暗号化をしていないため、物理的な機器取得への耐性は別途課題です。
現在は1台・1質問1回答。会話履歴、割込みは未対応。実機TLS・ホットスポットでの会話・再起動後の再接続は段階的に検証します。
