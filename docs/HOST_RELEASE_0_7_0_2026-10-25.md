# Windowsホスト0.7.0 正式版

2026-10-25 / R01 / 対象: Windowsホストのみ。GitHub公開・main統合作業中。

## 対象と変更

利用者の正式版パッケージ化・GitHub push/main mergeの指示に基づく。0.7候補の接続処理を維持し、ホスト版数と配布資料を0.7.0に整える。端末は既存0.6.0-rc.1を使用し、ソフト・AP名・APパスワード・呼びかけ登録を変更しない。端末更新用ファイルは本Releaseに含めない。

「スタックチャン接続」でホスト待受、保存済み端末の受付、必要なAP自動設定を行う。初回自動設定の対応は有線上流・未接続の物理Wi-Fi1台・2.4GHz/WPA2・対象AP1台。送信後20秒維持、取消/PC復帰、非再送、秘密情報非表示を含む。[実装・レビュー・実機結果](HOST_AP_PROVISIONING_IMPLEMENTATION_R01.md)と[利用手順](../desktop/README.ja.md)を参照。

## 検証の区別

- 実機: 候補EXEで利用者が設定引継ぎ、保存済み接続、スマホなしAP自動設定、手動質問の回答音声・口パク・待受復帰を確認した。
- PC読取り: 有線InternetAccess、物理Wi-Fi未接続への復帰、ホットスポットOn/2.4GHz/WPA2、接続台数1、TCP48443待受を確認した。
- 候補のコード検証: Python77件、Node38件、EXE自己診断16項目成功。レビューの未解消指摘0件。正式版は同じ振舞いのソースを使い、版数・資料だけを変更する。
- 正式版でもPython77件・EXE自己診断16項目成功、自己診断のAPI呼出し0。候補と正式版のランチャー11ソースを照合し、差分は`desktop/settings.py`の版数だけだった。Node38件は同一の処理ソース/同じNode24.15.0で検証済み。候補版の実機確認を、正式版バイナリで再実施した試験とは扱わない。
- 公開対象222ファイル、未統合履歴38 blob、配布入力1370ファイル、7資産（ZIPの展開内容を含む）を、実際のキー値・既知キー/トークン形式に照合して一致0件。実際の設定値は表示・保存していない。自己診断前後の秘密設定5パス同一。配布マニフェスト・ソースSHA一致、ZIP6エントリのCRC・展開後バイト一致を確認。
- GitHubのPR/Release/同期は結果追記待ち。監査詳細はGit除外の`.pio/release-sync-20261025/release-audit.json`に保持する。

## 配布物

作成先は`releases/StackchanHost-0.7.0-win-x64/`。ZIPを展開して`StackchanHost.exe`を起動する。Node/Pythonの事前インストールは不要。旧版0.6.0-rc.1・候補0.7.0-rc.1は保持する。
