## 対象と変更

利用者の正式版パッケージ化・GitHub push/main mergeの指示に基づく。0.7候補の接続処理を維持し、ホスト版数と配布資料を0.7.0に整える。端末は既存0.6.0-rc.1を使用し、ソフト・AP名・APパスワード・呼びかけ登録を変更しない。端末更新用ファイルは本Releaseに含めない。

## 公開後の整理

利用者が候補ホストを停止・終了した後、ローカル旧ホスト0.6.0-rc.1、候補0.7.0-rc.1、レビュー前候補、およびビルドステージ・一時作業・npmキャッシュ・空の試験フォルダ・公開用一時ツールを削除した。公開済みの過去GitHub Releaseは履歴として残す。

正式版7資産・現行端末ファームウェア・秘密設定5パスは削除前後で同一。再ビルド用Python環境・固定Node入力、端末ビルド/保存イメージ、過去の検証記録と文書アーカイブは保持した。[削除結果](release-records/2026-10-25/CLEANUP.json)に対象・件数・論理サイズ・残存0件を記録する。論理サイズはディスクの実空き容量やNASの履歴保持容量とは異なる。
