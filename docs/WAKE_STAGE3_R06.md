# 第3段階R06: 同じ操作3回で呼びかけを登録

2026-10-19（日本時間）/ R06。対象: AtomS3R + Atomic Voice Base A149、Arduino-ESP32 2.0.17、PlatformIO atoms3r-gemini-device。依存固定版はplatformio.iniを参照。目的: 利用者の要望に従い、録音・別操作の照合・保存確認を分けていた複雑な学習手順を、同じ操作3回と自動整合確認へ置き換える。

## 操作と整合性

Sleepingで画面ボタンを約7秒長押しして離すと登録へ入る。1/3、2/3、3/3のそれぞれで短押しし、開始音と準備を待ち、Learning callの発話案内で同じ呼びかけを話す。3回とも同じ操作・画面を使う。各回のビープ完了後700ms待ち、初期400ms破棄と600ms環境音測定は維持する。

3回分の特徴をRAMで保持し、全3組のDTW距離が既存wakeThreshold未満であることを確認する。一致した3回のうち他の2回との距離合計が最小の代表特徴を既存の1パターン形式で保存する（同点は先の録音）。複数モデルを並列に検出する方式にはしない。最終保存確認の短押しは省き、3回が整合したら自動登録する。

3回終了前、品質不足、整合不一致、保存失敗では旧登録を維持する。失敗理由を表示してから短押しで最初の録音からやり直せる画面を出す。長押し2秒（案内は約3秒）または無操作30秒で取消。開始した各録音中はボタン押下で取消。全特徴と録音バッファは終了時に解放/消去する。録音と特徴はGoogleへ送信せずログにも保存しない。

- 登録UI21/21: 同一操作3回だけで自動保存、各回700ms待ち、各段階取消、途中I/O失敗、失敗後3回すべての再取得、旧登録保護、USBからの質問拒否。
- 保存29/29: 1/2回のみの保存拒否、2回目と3回目だけの不一致、閾値一致の拒否、代表特徴の選択、4回目追加による検証失効、保存/改名/読戻し故障と復旧。
